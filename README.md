ABOUT
=====

Thank you for choosing CandleAlert Pro!

CandleAlert Pro is a lightweight Windows application that helps traders stay
focused by notifying them whenever a candle closes.

Instead of constantly watching your charts, simply keep the application
running in the background and receive an audible alert at the exact candle
close time.

Whether you trade the Indian Stock Market, U.S. Stocks, Forex, or
Cryptocurrency, CandleAlert Pro helps ensure you never miss an important
trading opportunity.

===============================================================================
INSTALLATION
============

1. Download the latest release.

2. Extract the ZIP file.

3. Ensure the following files remain together:

   CandleAlert.exe
   settings.json
   sounds\

4. Double-click CandleAlert.exe to launch the application.

No installation is required.

===============================================================================
HOW TO USE
==========

1. Launch CandleAlert Pro.
2. Select your preferred market.
3. Choose the candle timeframe.
4. Select your preferred alert sound.
5. Click Start Monitoring.
6. Leave the application running while the market is open.
7. A sound will automatically play whenever a candle closes.

===============================================================================
CUSTOM ALERT SOUNDS
===================

You can use your own notification sounds.

Steps:

1. Open the "sounds" folder.
2. Copy any .wav file into the folder.
3. Restart CandleAlert Pro.
4. Your new sound will automatically appear in the sound selection list.

===============================================================================
SYSTEM TRAY
===========

Closing the main window does not necessarily stop the application.

When minimized to the system tray:

• Alerts continue running.
• The application uses very little system resources.
• You can reopen the application from the tray icon at any time.

===============================================================================
START WITH WINDOWS
==================

CandleAlert Pro can automatically launch when Windows starts.

Simply enable the "Start with Windows" option inside the application.

This ensures CandleAlert Pro is ready whenever you begin your trading day.

===============================================================================
TROUBLESHOOTING
===============

No Sound?

• Check that your speakers are working.
• Ensure Windows volume is not muted.
• Verify that a valid alert sound is selected.
• Confirm the .wav file exists inside the sounds folder.

Application Doesn't Start?

• Make sure all required files are present.
• Try running the application as Administrator.
• Ensure your antivirus has not blocked the application.

Custom Sound Doesn't Appear?

• Only .wav files are supported.
• Restart CandleAlert Pro after adding new sounds.
